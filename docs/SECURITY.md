# Seguridad para contribuyentes

Este repositorio es público. No adjuntar capturas de sesiones, API keys, tokens, nombres de cuenta reales, direcciones de infraestructura privada, cookies, proxies, bases de datos, logs en bruto, configuraciones `.env`, claves privadas o archivos `Vyro_Prime_Config.json` reales.

Los endpoints remotos se sustituyeron por `https://example.invalid`. Nunca apuntar un test del repositorio a producción. El código es para lectura y pruebas con datos sintéticos, no para acceder a cuentas ajenas ni operar infraestructura real.

Reportar vulnerabilidades por canales privados con el propietario; no abrir un issue que revele credenciales. Un cambio requiere revisión, pruebas aisladas y reversión demostrada.
