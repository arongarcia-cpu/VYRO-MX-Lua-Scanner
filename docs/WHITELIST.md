La whitelist comercial es una política autorizada, no una lista de todo lo detectable por el Lua. Halloween requiere procedencia `world_spawn`, una identidad consistente y una confianza mínima comprobable. Las entradas de Enchanted Forest requieren identidad validada.

No publicar valores de API key, sesiones ni listas de cuentas en los archivos del repositorio.
